# 指标登记表（Metric Registry）

审查学位论文前必须先填这张表。**表填不满的指标，不允许出现在正文表头。**

## 为什么要这张表

缩写有两个独立的出错点：

- **没定义**：表里用了 `SCH`，正文从没解释 → 评委会问"这是什么"。
- **定义错了**：写了全称，但全称跟原文不一致 → 评委按全称去查原文查不到，反而像编的。

第二种比第一种严重。它看起来完整，只有对照原文才能发现。

## 模板

| 缩写 | 中文名 | 英文全称 | 定义 / 公式 | 来源（文件:行 或 DOI） | 尺度 | 方向 |
|---|---|---|---|---|---|---|
| CSD | 对比风格描述子 | Contrastive Style Descriptor | 风格嵌入余弦相似度 | 待填 | 0–1 或 0–100（随实现） | ↑ |
| SCH | 风格—内容调和 | Style-Content Harmonic | `√(CSD·CLIP-I)` | 待填 | 随 CSD 尺度 | ↑ |
| STM | 风格—纹理匹配 | Style–Texture Match | 高通方向直方图余弦 | 待填 | 0–1 | ↑ |

## 填写规则

1. **英文全称逐字取自原文**，不按语感翻译。`Style–Texture Match` 与 `Structural Texture Metric` 只差几个词，但后者根本不存在。
2. **来源必须可定位**。写「源文件:行」或 DOI，不写「原文里有」。查不到的标 `待作者补充`，不要空着，也不要猜。
3. **复合定义照样登记**。`SCH=√(CSD·CLIP-I)` 这种看起来像临时拼的公式，很可能就是原文定义；登记时附行号，不要因为"不像标准指标"就否定。
4. **同名不同尺度要分行登记**。两种 CSD（百分制与小数制）是两条记录，各自标尺度，并在正文说明不可换算。
5. **方向列必填**。↑ 越高越好、↓ 越低越好。缺少方向的指标读者无法解释数值。
6. **表随论文走**。放在项目 `state/` 或附录旁，审查、改稿、答辩都用同一份。

## 审查时的用法

1. 扫正文与表头，列出所有出现的缩写。
2. 逐个到表里查。表里没有 → 报「指标未定义」。
3. 表里有 → 对照正文写的全称与公式，逐字比较。不一致 → 报「定义与原文不符」。
4. 同一指标在两章出现两种尺度 → 报「尺度混用」，但不做换算。

## 常见坑

| 坑 | 表现 |
|---|---|
| 缩写对、全称错 | 全称是另一个同领域术语，读者查不到 |
| 公式合理但非原文 | 自己推导了一个自洽式子写进论文 |
| 只给公式不给方向 | 读者不知道 0.68 算好还是差 |
| 两章各用一个名字 | 第 3 章「标记」、第 4 章「词元」 |
| 尺度混写 | 百分制与小数制在同一段比较 |

## 复合指标必须逐行验算

遇到 `X = f(A,B)` 这类复合指标，**把表里每一行都代进去算一遍**，不要只看自己那一行。

- 若**多数行**符合公式、**只有一行**不符合 → 多半是那一行的数字录入错了（某个分量抄错一位），而不是公式写错。
- 若**多数行**都不符合 → 可能是公式抄错，或该表用的是另一个版本的指标。

**处理分级（真实经验总结）**：

1. **第一梯队：优先核查作者原始实验底账与运行日志**。
   - 典型案例（ArtFID）：官方定义为 $(1+\mathrm{LPIPS})(1+\mathrm{FID})$，表中 6 个基线完全符合，唯独提出方法一行报告 ArtFID=25.029、LPIPS=0.483、FID=16.877，计算 $(1+0.483)\times 16.877=25.029$ 漏加了 1。反向验算 $(1+0.483)(1+\mathrm{FID})=25.029 \implies \mathrm{FID}=15.877$。经作者核对原始实验底账，证实真实 FID 为 **15.877**，发表时小论文表格首位数字录入错位。
   - 处理方式：大论文在 FID 列修正为真实值 15.877，正文恢复官方完整公式 $(1+\mathrm{LPIPS})(1+\mathrm{FID})$，表注注明按公式由两列计算，评委现场验算 $(1+0.483)(1+15.877)=25.029$ 精确吻合，全表 100% 自洽；已发表的小论文不动。
2. **第二梯队：若无法核查原始底账或无法证明录入笔误**。
   - 严禁自行编造数字填补。此时正确做法是**不展开公式**，只引用文献定义，并在表注说明各分量的含义，并在事实库中登记矛盾与处理依据，避免读者与下一轮审查重复发现、重复改。

**查证顺序**：先找指标原始论文的公式（给出版次与式号），再核对实验原始底账，最后才决定动不动论文。
