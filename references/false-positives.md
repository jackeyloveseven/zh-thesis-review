# 误报与不要改（False Positives & Do-Not-Touch）

审查的价值一半在**少报**。这一页记录实践中确认的误报、不能改的情形，以及"改了会更糟"的陷阱。

## 一、确认的误报

### 1. 「说明」计数偏高不等于文风差

`说明` 在中文科技写作里是中性动词，很多地方无法替换（"这说明分布存在偏移"换成"表明"只是换词，不改信息）。只有当**同一段两个以上**、或**整章每段都以"这说明"开头**时才算问题。

### 2. 「本章研究 X 方法」不必然是主体剥离

若该方法确实是作者提出，且上下文已交代"本章提出……"，后文用"本章研究该方法的训练策略"是正常的。判定要看**首次引入**那一句有没有明确归属，而不是查所有"本章研究"。

### 3. 「两项工作」不必然是拼稿痕迹

学位论文常由多个研究内容组成，"两项工作""两个研究阶段"是合法表述。真正的问题词是「两篇」「拼接」「合订」「整合」「补充材料」。若用户明确反感，再统一替换为"两种机制"。

### 4. 「表中」有时是紧邻的省略

正文紧接在表格上方，写"表中给出……"，即使没有 `\ref`，读者也能看到表。这种情况不报 L0，只在跨页或跨节时才报。

### 5. 英文缩写出现在摘要

摘要里用 CSD、CLIP-T 这类领域通行缩写，即使未定义，多数评委也接受。定义要求主要针对**正文表头**和**首次出现处**。

### 6. 图注里保留原始英文标签

从原论文裁下来的图，内部标签（如 Canny、AFF）是图片像素的一部分，不能改。只有当正文**文字**里出现这些词时才需要处理。

### 7. 空白页

前置部分的空白页通常来自"每部分另起右页"的模板设定，属格式规范，不是缺陷。是否删除由作者按学校要求决定，审查只提示。

### 8. 结论章的局限性与展望不等于“自贬递刀”

学位论文最后一章规范上允许且提倡有「局限性与未来工作」小节，客观界定外部约束条件（如超高分辨率下的显存开销、多语种泛化能力）是学术严谨性的体现。**只有在正文方法章、实验章小结中直白承认核心实验缺失、未能验证核心假设或情绪化认输**（如“未能验证”、“没有开展基线对比”、“表现较差”）才算 L0 递刀。

### 9. 致谢与引述中的“我们”

致谢部分写「我们课题组」「我们师生」、正文直接引述外部学者论著中的话（如「Turing 指出：“我们考虑……”」）、以及传统数学推导约定（如「若我们取矩阵为正定」），不属于小论文多作者机翻残留，不予报错。只有正文叙述自己工作时通篇「我们提出」「我们设计」「我们发现」才算 L1。

### 10. 紧邻图表的省略指代

正文紧邻表格/插图环境（上下 400 字符内存在 `\begin{table}`、`\begin{figure}`、`\begin{tabular}`、`\begin{sidewaystable}` 等），写“表中给出……”“如图所示”，读者视线无需翻页即可见，属于合理紧凑行文，不计入幽灵表图。

### 11. 「特征图中」「计算图中」不等于幽灵插图

在计算机视觉与深度学习领域，「卷积特征图中」「反向计算图中」「中间特征图中」属于数学/数据结构专有名词（feature map、computation graph）加方位后置词“中”，表示“在特征图内部”或“在计算图反向传播过程中”，并非指代论文的浮动体插图，严禁计入幽灵插图误报。

### 12. 「其实际效果」「其实验结果」不等于出格口语“其实”

中文古汉语与科技写作中，“其”是广泛使用的第三人称代词（相当于 its / their），后接“实际”“实验”“实施”“实质”“实体”构成严谨学术语块（如“验证其实际效果”“展示其实验结果”），绝非口语副词“其实（actually）”，严禁误报。

### 13. 「特征拼接」「词元拼接」不等于拼稿痕迹

深度学习模型中，多头注意力后的拼接（`torch.cat`）、跨模态词元轴拼接、状态向量拼接是核心张量操作（如“分别计算注意力后拼接并投影”），严禁误报为小论文拼接或论文拼稿痕迹。只有谈论论文章节组织或实验强行缝合（如“两篇工作拼接而成”“把不同协议拼接为统一倍率”）才构成 L1 拼稿痕迹。

### 14. 浮动体独立计数原则（图与表不可跨类别交叉判定乱序）

LaTeX 中 `figure`、`table`、`algorithm` 各自维护完全独立的编号计数器（`\thefigure`、`\thetable`）。正文中先引用“图 3.1”再引用“表 3.1”，即便源码中表格环境写在插图环境上方，也绝不构成乱序。只有同类别的浮动体（如先引图 3.2 再引图 3.1）才算乱序。

### 15. 符号表已有条目及摘要缩写不重复报未定义

若论文前置部分已包含专门的符号表（`denotation.tex`），并在其中登记了全称与度量方向（如 CSD、STM、SCH），正文直接使用属于规范写作，不应报首现未定义；摘要部分使用领域通用缩写（如 CLIP、FID）亦受通行惯例豁免。

### 16. 脚本清理 `\ref` 后出现的「如表 所示」

机械检查会把 `表\ref{tab:x}所示` 清理成 `表 所示`，再据此报「表号为空」是误报。核对时回到源码，确认 `\ref` 指向的 label 在同一章存在即可。

### 17. 「原文献」「原文本」不等于拼稿词「原文」

`原文` 是要报的拼稿痕迹，但 `原文献`（original paper）、`原文本`（original text）是正常学术表述。正则需排除 `文献档稿` 等后缀。

### 18. 段落跨页不等于排版缺陷

正文段落被浮动体推到下一页，是 LaTeX 的正常分页行为。只有当断点落在「两项／分量」这类**把一个词或短分句劈开**的位置时才值得处理；处理方式是压缩句子让断点落在句界，而不是反复调浮动参数（`[!htbp]` 改 `[htbp]` 通常无效——空间不够就是不够）。

### 19. 补表注可能撑破符号表

给表格补注、给符号表条目补说明时，行高会变。长条目会把 `longtable` 顶出一整页，产生「只含一行注的残尾页 + 纯空白页」。对策：**多义说明写进表下方的统一注里，不要塞进表格条目**，改完必须重新数页并检查空白页。

### 20. 文档类、宏包与通用软硬件名不等于未定义缩写

`DUT-thesis-grd`（学校学位论文模板）、`NVIDIA`、`RTX`（GPU 硬件型号）、`SD`（Stable Diffusion 通用代称）、`IP`（IP-Adapter）属于标准技术环境或宏包标识，不属于正文需要额外给出学术定义的度量指标。

### 21. 按文档物理包含顺序审阅，避免字母序误报

LaTeX 工程应按主文件（如 `MA Thesis.tex`）中 `\include` / `\input` 的真实读取顺序（`chapter1` → `chapter2` → … → `app1`）确定各术语的“首现位置”。若按文件名字母排序，`app1.tex` 会排在 `chapter1.tex` 之前，导致在正文中早已明确定义的缩写（如 LRS 在第 1 章已定义全称）在附录被误判为“首现未定义”。

## 二、绝对不能改

### 1. 不同协议的同名指标不能换算

同一指标在不同主干、不同测试集上可能有不同尺度（例如百分制 50.6 与小数制 0.640）。把它们相除、归一、排名，会直接制造一个**不存在的结论**，评委一横向对比就会认定后一章碾压前一章。

正确做法：保留原值，在指标定义处和表头标注尺度，正文用一句话说明"两者协议不同，不构成直接比较"。

### 2. 指标定义必须回查原文，不能凭印象补，也不能凭印象否定

审查报告写「指标 SCH 缺定义」是对的，但若要给出定义，必须能指到**源文件行号**。查不到就标「待作者补充」，不要凭合理性编一个，也不要凭印象断言别人给的是编的。

同一次实践里出现过两种相反的情况，正好说明为什么必须查：

- **复合指标的公式可能是原文的**：例如 SCH 就定义为 `√(CSD·CLIP-I)`，审查者一度以为是臆造，判断错误。
- **缩写的英文全称可能被写错**：STM 的原文是 Style–Texture Match，却被写成 “Structural Texture Metric”。缩写对、全称错，比缺定义更危险——评委按全称去查会查不到，反而像是编的。

结论：公式与全称一律以源文件为准，报告里附「文件:行」。同时，**不要因为"这个公式看起来很合理"就判定它是编的**，很多指标本来就是复合定义。

### 3. 不要为了"统一"改术语既有译名

同一概念在全文可能有约定俗成的译法（"词元"而非"标记"、"主干"而非"骨干"）。审查时以**全文一致性**为准，不要按个人偏好换词，否则会引入新的不一致。

### 4. 不要删限定换取流畅

学术写作的限定句是严谨性的一部分。把"这并不意味着 A"删掉，等于把结论放大。正确改法是转成正面界定："本实验界定的是 A 的适用边界"。

### 5. 不要把复现内容写成"提出"

若某章包含对他人方法的复现、对比或改进，保留归属（"该方法由 X 等提出，本文在其基础上……"）。只有作者原创部分才用"提出""本文设计"。

### 6. 未核实的 DOI 不要回填

模糊检索（Crossref 按题名）的误配率极高：同名的不同论文、同题不同年份、预印本与正式版。审查只负责指出"缺 DOI"，回填必须逐条人工确认题名、作者、载体三者一致。

### 7. 不要把“自贬”改成虚夸或一删了之

发现正文直白写了「没有开展人类偏好用户研究」时，直接删除整句会使后续结论悬空，盲改称“主观效果表现优异”则构成学术不端。正确改法是**正面界定适用条件与研究范畴**（如「本研究重点考察客观量化指标与专家定性效果，大规模人群主观偏好评测留待后续结合实际工业场景拓展」）。

### 8. 机械将“我们”全量替换为“本文”造成语病

「我们提出」可改为「本文提出」；但「我们观察到 / 我们发现」不能机械替换为「本文观察到 / 本文发现」（论文无感官），应改为「实验表明 / 实测观察到 / 可视化结果显示」。

## 三、二次改错案例（真实发生过的）

| 错误动作 | 后果 | 正确做法 |
|---|---|---|
| 把百分制 CSD 除以 100 去"统一" | 制造跨章碾压的假结论 | 标注尺度，说明协议不同 |
| 补公式或全称时未附来源 | 可能与原文不符，答辩被问即穿 | 附「源文件:行」，查不到标待补 |
| 批量把"说明"换成"表明/显示" | 出现新的单调，且语义错位 | 只改重复段落中的一部分 |
| 改标题时按搜索结果取第一条 | 标题写到了无关条目上 | 用唯一标识（DOI / item key）定位，改完复核 |
| 批量替换未断言唯一命中 | 静默漏改或多改 | 每次替换断言命中数 = 1，失败即报 |
| 删除"不严谨"的限定句 | 结论被放大，评委追问依据 | 改写成正面界定 |
| 把两篇论文的数值并列成一张表 | 评审直接问"这两个能比吗" | 分表呈现，正文说明不可比 |
| 把“没有开展用户研究”直接删掉 | 盲审专家追问“主观任务为何无人工评测” | 改写为正面适用边界与后续扩展 |
| 批量把“我们发现”改成“本文发现” | 出现多处拟人化病句与语病 | 改为“实测观察到 / 实验表明” |
| 小论文直译“文中给出 1.9 倍” | 读者与评委翻遍全节不知指哪篇文献 | 明确指代主体（如“理想化模型给出约 1.9 倍”） |
| 论文保留“假装超参数一致”等口语 | 答辩委员会当场质疑实验严肃性与态度 | 改为“在统一超参数配置下进行对照” |
| 误把“特征图中”当成幽灵插图报出 | 混淆数据结构与论文排版浮动体 | 加负向零宽断言排除特征图/计算图 |
| 误把“其实际效果”判为口语“其实” | 破坏规范的第三人称代词行文 | 排除“其实”后接际/验/施/质等字 |
| 把表格与插图混合判定引用乱序 | 误报合法排版（图表计数器独立） | 按 `fig:`、`tab:`、`alg:` 分类独立检查 |
| 为消除 `1/2.5` 写成「40%（即 1/2.5）」 | 同一句把同一件事说两遍，被批评的写法还在 | 直接写「为其 40%」，删掉括注 |
| 把「说明」全量换成「表明」 | 从一个垄断换到另一个：说明 104→1，表明涨到 68，占比仍过半 | 只改三分之一，按语义分配：数据用表明、观测用显示、机制用说明 |
| 缩写补了全称但没核对原文 | 全称是别的同领域术语，评委按全称查不到，反像编的 | 按 `references/metric-registry.md` 逐条登记「源文件:行」 |

## 四、审查者的自律

1. **不追求条目数量**。一份 15 条、每条都能指出具体位置和改法的报告，比 60 条"建议优化表述"有用。
2. **每条必须能回答"为什么会被抓"**。答不上来的，说明是自己的偏好，不报。
3. **区分确认与疑似**。机械命中的标"疑似"，人工读出来的标"确认"，不确定的单列。
4. **先读事实库再读正文**。没有数字登记表就审数字，等于用记忆对账。
5. **改完必须重编译并重跑检查**。文本改动会改变断行，可能引入新的 overfull 或浮动体乱序。
